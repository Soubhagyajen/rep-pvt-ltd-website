# Development Rules

Always read project-context.md first.

Always read ui-guidelines.md.

Never change colors.

Never redesign logo.

Never create huge components.

Maximum component size:

200 lines.

Split into reusable components.

Always use:

TypeScript

Tailwind

Shadcn

Framer Motion

Lucide

Use Server Components whenever possible.

Never duplicate code.

Never hardcode repeated data.

Store content inside data/.

Every component must be responsive.

Every component must be accessible.

Use semantic HTML.

Optimize images.

Use next/image.

Lazy load where appropriate.

Every component must support dark mode later.

Always write production-ready code.

No placeholder lorem ipsum.

No inline CSS.

No inline SVG unless necessary.

Use reusable utility functions.

Follow clean architecture.
